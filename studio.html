      Writing an effect

      Shader effects are Shadertoy-style GLSL ES 3.0 shaders. Write a mainImage function; the camera is iChannel0.

      • vec3 iResolution: output size in pixels
      • float iTime, iTimeDelta, iFrameRate; int iFrame
      • vec4 iDate: year, month, day, seconds
      • sampler2D iChannel0: the camera; iChannel1–3 are black
      • vec4 iMouse is always zero

      texture2D() works as an alias of texture().

      Writing an effect

      JavaScript effects run in a sandbox with no network access. Define:

      • async setup({ mediapipe }) (optional): runs once when the effect loads.
      • draw(frame, ctx, info): runs for every frame. frame is an ImageBitmap, ctx a 2D context the size of the frame; whatever you draw is the output. info has time, width, height and frame (a counter).

      MediaPipe is bundled:

      • await mediapipe.faceLandmarker(options): a FaceLandmarker; call detectForVideo(frame, info.time).
      • await mediapipe.selfieSegmenter(options): an ImageSegmenter for separating people from the background.
      • mediapipe.vision: the whole @mediapipe/tasks-vision API, with mediapipe.fileset and mediapipe.models for building other tasks.

      A scene's effects run in order after its background, so frame already has the background and any earlier effects.
